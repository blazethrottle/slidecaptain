# 실전 파일럿 관찰지 (v0.1, 2026-08-31 준비)

> 목적: 실제 업무 보고 1건을 Slide Captain으로 제작하며 관찰을 기록한다. 이 기록이 단계 5 계획서의 입력이 된다.
> 채우는 사람: 사용자 본인. 빈칸과 표에 자유롭게 메모하면 되고, 형식을 지킬 필요 없다.
> 회사 기밀 주의: 이 파일은 GitHub(개인 저장소)에 올라가는 저장소 안에 있다. 자료 내용이나 회사 내부 정보는 적지 말고, 앱 사용 경험만 적는다.

## 시작 방법

1. 저장소 루트의 `SlideCaptain실행.bat`을 더블클릭한다 (서버 창이 열리고 브라우저가 http://127.0.0.1:8765 로 열린다. 서버 창을 닫으면 앱이 꺼진다)
2. 프로젝트를 만들고, 실제 리서치 자료(마크다운이나 텍스트)를 붙여 넣는다. 자료는 이 PC 밖으로 나가지 않는다(127.0.0.1 전용). 단, AI 생성 시 자료 내용이 본인 Claude 구독 호출에 포함된다
3. 흐름: 자료 입력 → 보고 정보 저장 → 구조안 생성 → 표에서 수정 후 승인 → 장별 생성 → 편집 → PPTX 내보내기 → PowerPoint로 열기
