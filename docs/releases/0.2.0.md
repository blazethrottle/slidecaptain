# SlideCaptain 0.2.0 로컬 앱 릴리스

2026-10-02 사용자 요청: 개발 마무리와 Windows·Mac 로컬 앱 배포. 서비스에 치명적이지 않은 부족은 릴리스 후 보완한다. 이전 준비 인계의 main 병합·배포 제외 범위는 이번 요청으로 확대되었다. 실제 AI 호출 예산은 추가하지 않는다.

## 제공 범위

자료 업로드, 보고 구조와 근거 계획, 편집 가능한 템플릿·도식·차트, 초안 PPTX 내보내기, 스냅샷·복구·검수 이력을 제공한다. 본인 Claude 또는 ChatGPT 연결과 모델 선택을 사용하며 다른 제공자로 자동 전환하지 않는다. 제출본 게시에는 기존 실제 렌더·서명 검수·현재성 관문을 유지한다.

배포 ZIP은 화면을 포함한 Python wheel, 고정된 runtime 의존성, OS별 실행 파일과 설치기를 포함한다. Python 3.13 이상과 최초 설치 인터넷이 필요하다. Node.js 없이 사용할 수 있다. 새 버전은 별도 설치 폴더와 가상환경을 사용하고 기존 사용자 자료 폴더를 보존한다. 제품·버전·화면 준비 상태를 확인해 다른 앱이나 구버전 서버로 잘못 접속하지 않는다.

## 근거와 남은 작업

이전 공개 커밋 `8561b4e`의 [Windows·macOS CI](https://github.com/blazethrottle/slidecaptain/actions/runs/36937215634)가 성공했다. Windows 핸들/경로 시간 대조, 내보내기와 검수 증거 봉인, 디렉터리 이름 변경 보호 및 취소 후 생성 잠금 문제를 수정했다. 사용자는 Windows 환경 작업 종료를 알렸고 GitHub 보고를 참조하도록 지정했다. 조회 시 GitHub issue·PR에는 별도 결과 보고가 없었으며, 저장소의 [준비 인계](../handoffs/2026-10-02-windows-review-ready.md)는 실제 PowerPoint와 사람 평가를 미실행으로 기록한다. 이번 릴리스는 그 빈칸을 통과로 바꾸지 않는다.

릴리스 후 보완할 항목은 다음과 같다.

- 실제 PowerPoint 표시·편집·렌더와 독자 품질 평가 자료 대조, Q5의 전체 다장 보고서 품질 수용.
- OS별 완전 독립 실행형 설치본과 코드 서명. 이번 배포는 Python이 필요한 로컬 패키지다.
- 도식의 분기·비인접 경로와 다른 폰트/읽기 프로필 지원, 장/본문 전체 자동 재생성 등 기존 미지원 범위.
- 사용자에게 알려진 비공개 staging 파일 누적의 안전한 정리 방식.
- 외부 고객/유료 제품의 라이선스·브랜드·제공자 약관과 서비스 운영 검증. 이번 개인용 출시 범위와 별도다.

최종 검증 기록과 아카이브 해시는 [릴리스 QA](../qa/2026-10-02-local-release.md)에 남긴다.
