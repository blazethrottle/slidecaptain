## 검사

GitHub Actions에 `dependency audit` 잡을 더했다. PR과 main 푸시에서 돈다. 기존 Windows, macOS 검증 잡과는 별도다.

- Python: `pip-audit`로 `backend/requirements-release.txt`를 검사한다. 배포 잠금에 권고가 있으면 실패한다.
- 프런트와 독립 앱: `npm audit --audit-level=high`. high 이상이면 실패한다.

## v0.2.0 이후 main에 합쳐진 것

버전 번호는 0.2.0으로 머물러 있었고, 기능은 main에 들어가 있었다. 0.2.1이 그 차이를 배포 버전에 담는다. 사용자 안내의 본문은 업데이트 안내 문서다. 저장소 이력에서 묶으면 다음과 같다.

- 개정판 보고 흐름: 보고 유형과 보고 목적, 직접 수정, 복구 화면에서 후보를 비교하고 반영.
- 0.2.0이 쓰던 프로젝트는 새 기능을 쓰지 않으면 그대로 연다. 새 유형, 보고 목적 입력, 직접 수정을 쓴 프로젝트는 0.2.0에서 복구 필요로 보인다. 함께 쓰는 방법은 업데이트 안내 1절과 2절이다.
- 장 제목 28pt, 표지 36pt, 섹션 32pt와 긴 제목 자동 맞춤. 비교 차트는 표 자리의 80%를 기본으로 하고, 들어가지 않으면 표 자리 전체에 그린다.
- 차트 값의 소수 둘째 자리 표시, PowerPoint 값 축 눈금 정리, 가로 막대 그림 영역.
- Claude 모델 목록을 이 PC의 Claude Code에서 받고, 추론 강도를 저장해 생성에 전달한다.
- 생성 세션에서 Claude Code 내장 스킬과 슬래시 명령을 끈다. 요청한 추론 강도를 작업 기록에 남긴다.
- Windows에서 시간대가 어긋나던 문제, PowerPoint 렌더를 연달아 실행하면 거절되던 문제.

## 이번 릴리스에서 남긴 권고

high는 없다. moderate이고, 고치려면 메이저를 바꾸어야 해서 남겼다.

- 프런트 `minimatch` [GHSA-g3hv-75wg-m249](https://github.com/advisories/GHSA-g3hv-75wg-m249). 잠금의 minimatch는 5.1.9다. 권고의 수정 버전은 11.0.1이고, npm이 제안하는 경로는 `openapi-typescript`를 7에서 6.7.6으로 내리는 것이다. 타입 생성 도구의 메이저 다운그레이드라 하지 않았다.
- 독립 앱의 `electron-builder` 26.15.3 트리가 같은 minimatch 권고에 묶여 있다. npm이 제안하는 경로는 `electron-builder`를 20.23.1로 내리는 것이다. 패키징 도구의 메이저 다운그레이드라 하지 않았다.

이 항목은 로드맵 「2026-11-02 의존성 검사 이월」에 담당과 함께 올려 두었다. 검사를 끄지는 않았다. high가 생기면 CI가 실패한다.

## 확인하지 않은 것

이 준비에서 실제 AI 호출은 0회다. PowerPoint 표시와 서명, 게시는 하지 않았다. 두 OS CI가 이 브랜치에서 통과하는지는 푸시 뒤 실행 결과로 확인한다.
