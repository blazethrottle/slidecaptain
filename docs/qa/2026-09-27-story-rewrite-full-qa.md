# 보고 계획 재작성 구현 후 전체 QA

작성: 2026-09-27. 사용자 승인 범위는 기존 편집을 보존하는 보고 계획 재작성 구현과 전체 QA다. 이번 기능은 구현 및 로컬 QA를 통과했다. 실제 AI, Windows, PowerPoint와 독자 품질 검증은 완료하지 않았다. [구현 계획](../plans/2026-09-27-story-plan-rewrite.md), [인계](../handoffs/2026-09-27-story-plan-rewrite-handoff.md).

## 구현 결과

구조안 화면의 **기존 편집을 보존하며 계획 재작성**에서 질문과 지시사항을 입력하면 후보를 만든다. 후보를 읽고 본문 재검토가 필요함을 확인한 뒤 적용한다. 기존 장 ID/제목/결론/템플릿과 모든 슬라이드 내용은 유지하고 장 순서, 일반 장의 역할/주장/근거를 다시 계획한다. 보호 대상이 아닌 변경 자료와 새 자료의 근거를 선택할 수 있다.

도식의 역할/주장, 직접 및 간접 근거, 관련 비교와 산식은 보호한다. 보호 근거의 원문 전체 해시/위치/발췌가 달라졌다면 AI 호출 전 거절한다. 미리보기는 덱과 스냅샷을 저장하지 않는다. 적용은 미리보기 시점의 ETag와 전체 자료 해시, 내용 보존과 계획 현재성을 다시 검사한 뒤 스냅샷과 함께 저장한다. 적용 뒤에도 보존된 본문의 재검토 안내를 남긴다.

## 발견과 수정

| 발견 | 수정과 재검증 |
|---|---|
| 재작성 패널의 cleanup이 기존 일반 장 생성의 진행 잠금을 해제함 | 자신이 획득한 busy 상태만 해제. 실제 ProjectView 이탈 차단과 정상 대조군 확인 |
| 공통 생성 프롬프트가 기존 ID 보존 지침과 새 ID 부여 지침을 함께 전달함 | 재작성 전용 장 계약 분기. 기존 전체 구조안 생성은 기본 지침 유지 |
| 조건문과 미확인 질문의 수치 경고 누락 | 주장/조건/질문 전체 대조. 원문에 없는 합성 숫자 경고 확인 |
| 재작성 일반 문구의 금지 문장부호 정규화 누락 | 새 일반 문구만 정규화하고 보호 주장과 원문 관련 내용은 보존 |
| 390px 화면에서 기존 장 표가 문서를 493px로 넓힘 | 이름과 키보드 초점을 가진 가로 스크롤 영역 추가. 문서 폭 390px, 표 영역 358px/내용 478px 확인 |

앞 4건은 독립 리뷰에서 발견했고 마지막 1건은 브라우저에서 발견했다. 수정 뒤 같은 리뷰어가 최종 18개 파일의 해시를 기록했다. 초기 RED 로그는 증거로 보존했다. QA 하네스 자체의 잘못된 삭제 메서드, 품질 해시 키, PUT 응답 형식 가정은 실제 계약에 맞춰 수정했으며 제품 결함 수에 넣지 않았다.

## 브라우저와 관통 검사

합성 자료에서 일반 장의 원문을 10건에서 20건으로 바꾸고, 보호 도식의 원문은 그대로 두었다. Chrome에서 전송 동의, 후보의 새 순서/질문, 명시적 적용, 재열기와 영속적인 본문 재검토 안내를 확인했다. 기존 본문과 도식 3장은 그대로였다. 원문에 없는 숫자가 확인 질문에 있으면 후보에 경고가 표시됐다.

별도 합성 프로젝트에서는 미리보기 후 두 번째 작성자가 HTTP로 저장했다. 브라우저 적용은 412로 거절되고 질문과 후보가 유지됐으며 적용 버튼은 잠겼다. 최신 서버본 다시 읽기 후 후보가 해제됐다. 저장본과 ETag는 두 번째 작성자의 값 그대로였고 스냅샷도 늘지 않았다. 좁은 화면 검증 후 viewport를 원래대로 돌리고 검증 탭과 임시 서버를 종료했다.

실제 HTTP 검사에는 동의/ETag/CSRF/Origin 관문, 낡은 ETag와 자료 변경 거절, 후보 변조, 미리보기 무저장, 적용과 스냅샷, 중복 적용 거절, 렌더 순서, 수치 대조와 내보내기를 포함했다. 웹/CLI가 같은 폴더에서 서로 다른 버전으로 내보내고 기존 PPTX 해시를 보존했다. 3장 PPTX를 python-pptx로 다시 열어 기존 10건 문구와 편집 가능한 도식 요소를 확인했고 품질 sidecar의 파일 해시도 일치했다. 웹과 CLI의 제출본 요청은 계속 거절됐다.

## 미검증과 남은 개발

- 실제 Claude/ChatGPT 인증/생성, 실제 제공자의 구조화 응답 수용성과 토큰/비용은 검사하지 않았다. 모든 생성은 로컬 합성 프로바이더였고 외부 AI 호출은 0회다.
- Windows 실기기와 새 원격 CI는 실행하지 않았다. 확인된 기존 CI는 이전 HEAD의 결과이며 이번 변경 증거가 아니다.
- 이 Mac에 Microsoft PowerPoint가 없어 목표 앱의 표시를 검사하지 못했다. python-pptx 재열기를 실제 PowerPoint 결과로 대신하지 않는다. 독자 이해도/원문 해석/실제 보고서 품질도 미검증이다.
- 장 추가/삭제 및 본문 자동 재생성, 변경된 도식 보호 근거의 명시적 이전, 도식 AI 생성, 미지원 배치 확대와 검수 승인 저장/만료는 남아 있다. Q3/Q4 전체 완료로 표시하지 않는다.
