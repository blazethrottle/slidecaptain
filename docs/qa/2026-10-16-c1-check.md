## 2. 남은 것

- 이월표에 둔 것: 복구 화면을 다시 읽으면 "확인하지 못함" 행 표시가 사라짐(로드맵 이월표 (21), r2 `ga_afterReload`), 장 축약 행 문장과 비교 화면의 막힘 불일치((22), r2 `da_rows2`), W2 리뷰 기록 항목((23)), 복구 화면 목록이 마운트 때 한 번만 읽힘((20)).
- 이 Mac에서 볼 수 없는 것: 사람의 시각 판정, 화면 낭독기로 듣는 안내와 초점 이동, 실제 PowerPoint 표시, 한글 입력기, Windows 배율, 독립 앱(데스크톱) 창에서의 같은 흐름.
- 다른 탭의 묶음 시작은 API 호출로 만들었으므로, 탭 사이 알림으로 켜지는 복원 잠금 표시는 관측하지 않았다(서버의 409 방어만 확인).
