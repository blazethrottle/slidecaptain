## Chrome

`http://127.0.0.1:8829`의 독립 합성 저장소를 사용했다. 차트는 원래 표를 유지하며 0부터 시작하는 축과 두 값, 단위·기간·분모를 표시했다. 기존 부분 강조의 굵은 글씨가 보였다. 수치·요약 후보 검사의 결과와 의미 검수 미실행 안내를 확인했다. 문서 전체 후보의 미리보기에서 주제 변경 전후와 확인 체크를 보고, 체크 전 적용 비활성→체크 후 저장→장 주제 갱신을 확인했다. 확인 과정에서 성공 안내가 부모의 새 저장본을 외부 변경으로 분류하던 문제를 찾아 수정했다. 실제 외부 AI는 QA 화면에서 호출하지 않았다. 초안 내보내기와 검수 이력 상세에서 현재 바이트 일치, 실제 렌더/독립 검수 미수행과 게시 버튼 비활성을 확인했다. Mac에서 렌더 실행을 누르면 native 미지원의 미수행 기록을 남기며 게시 차단이 유지됐다. 화면 증거는 배치 `qa/qualification-chrome.png`에 있다.

## 실제 LUNA 비교

사용자 승인: Codex LUNA, 합성 자료만, 실패·재시도 포함 총 `provider.complete` 12회. 사용 모델은 `gpt-6-luna`, 자동 전환 없음.

독립 합성 업무 3개(물류 출고/재고, 영업 매출/환불, 설문 응답/표본)마다 일반·기존·개선 버전을 같은 자료와 질문으로 실행했다. 표지와 기존 도식은 고정 보존하고 일반 본문 한 장씩 생성했다. 9개 후보가 반환됐고, 별도 새 스레드에서 도구 정보를 숨긴 A/B/C AI 비평 3개가 반환됐다. 실제 호출 **12/12**, 실패·형식 재시도 **0**, 비용 **미확인(null)**. 원자료·프롬프트·응답·사용량·보존 대조는 `qa/live-distinct-luna/`에 있다.

AI 비평의 선호는 물류 일반+기존 동률, 영업 일반, 설문 일반이었다. 개선 버전 우세를 입증하지 않았다. 비평은 비교 자체가 불가능하다는 단정과, 수치만으로 결정할 수 없다는 한계를 구별하라고 지적했다. 같은 모델 계열의 AI 관측이며 독립 사람 검수나 제출 승인으로 취급하지 않는다. 이 결과를 유리하게 보이도록 후보를 고치거나 추가 생성하지 않았다.

9개 후보를 각 버전의 exporter로 원문 그대로 PPTX 출력했다. 사람 검수 폼과 익명 PPTX: `qa/live-distinct-luna/human-blind-pilot/index.html`. 원본 출력과 비공개 대응표는 별도 보존했다. 사람 판정 0/9, 수정 시간·비용 미확인. 최초 세 사례의 단일 페이지 비교이며 전체 보고서 품질 보정·미사용 사례 반복 검증은 완료하지 않았다.

## 실제 실행이 남은 조건

목표는 사용자가 지정한 최신 Windows PowerPoint다. 어댑터는 실행 당시 설치본의 version/build/실행 파일·글꼴·환경과 페이지 이미지를 기록한다. 특정 PC가 제공되지 않았고 Mac에 PowerPoint가 없어 실제 Windows 열기·편집·표시 검사는 미실행이다. 독립 검수자 신뢰 키와 실제 서명 receipt도 설정하지 않았다. 제출 자격은 차단 상태이며 기존 preflight의 `final_export_allowed=false`를 유지한다. 수동 검수 기록, 구조 검사, AI 비평만으로 이를 통과시키지 않는다.

안전 게시를 위해 임시 출력의 자동 삭제를 중단했다. 비공개 staging 디렉터리에 바이트가 남으므로 저장 공간을 사용한다. 별도의 소유권 확인 청소 도구는 아직 없으며 경로만 보고 무인 삭제하면 안 된다. 전체 로컬 저장소와 신뢰 registry를 함께 롤백하는 공격은 현재 로컬 신뢰 모델 밖이다.
