## 실제 LUNA 관통

새 승인 상한은 3회이며 `live-luna/report.json`의 실제 호출은 3회다. 모델은 `gpt-6-luna`다. 회사 자료 대신 접수, 검토, 전달의 합성 3문장을 사용했다. 입력/스키마는 호출 전에 저장했고 인증정보는 읽거나 복사하지 않았다.

| 호출 | 용도 | 관측 |
| --- | --- | --- |
| 1 | 일반 장 생성 | 성공 |
| 2 | 편집 보존 계획 재작성 | action 전용 주장을 핵심 답변으로 지정해 형식 관문에서 거절 |
| 3 | 재작성 형식 재시도 | 보호 필드 없이 유효한 변경안 반환, 적용/초안 출력 완료 |

입력 토큰 합계 32,678, 출력 930, 캐시 읽기/생성 0, 앱 기록 호출 시간 합계 24,859ms다. SDK 비용은 미제공이며 청구액을 추정하지 않는다. 서로 다른 응답/재시도 범위를 비용 또는 제공자 품질 순위로 비교하지 않는다.

고정 응답 관통과 실제 관통에서 아래 6개 확인은 모두 통과했다.

1. 미리보기는 저장하지 않는다.
2. 재작성 후 기존 슬라이드 내용을 보존한다.
3. PPTX를 다시 읽었을 때 3장이다.
4. PPTX와 품질 기록의 해시가 일치한다.
5. 도식이 편집 가능한 도형으로 남는다.
6. 미검수 상태의 제출본 내보내기는 거절된다.

오프라인 관통은 고정 응답 2회/외부 호출 0회다. 실제 관통은 `live-luna/`에, 초안은 그 안 `projects/quality-pilot/exports/합성 도식 보고_v001.pptx`에 보존했다. 원시 실행 기록은 후속 해석을 덮어쓰지 않는다.
