## 5. 상시 규칙

- 실제 AI 호출은 0회로 한다. `SLIDECAPTAIN_CLAUDE_CLI`는 늘 가짜 CLI(`backend/tests/fakes/fake_claude_cli.py`)나 없는 경로로 둔다. PATH의 `claude`는 로그인 상태다.
- 백엔드 전체 시험은 `env -u SLIDECAPTAIN_CLAUDE_CLI backend/.venv/bin/python -m pytest -q -p no:cacheprovider`로 돌린다.
- 사용자의 `~/slidecaptain-projects`는 열지도, 목록을 보지도(ls 포함), 쓰지도 않는다.
- push 전에 `backend/.venv/bin/python scripts/audit_public_repo.py`를 돌린다. push마다 `gh run watch`로 CI를 두 OS 끝까지 본다.
- 생성 문서와 텍스트에 엠대시(U+2014)와 중점(U+00B7)을 쓰지 않는다.
- 커밋은 시험 통과 뒤 경로를 지정해서 한다(`-a` 금지). 시험과 커밋을 한 명령에 잇지 않는다. 커밋 끝에는 세션 지시의 공동 저자와 세션 줄을 붙인다.
- 리뷰 담당은 git 작업 사본에서만 일한다. 본 클론에서 stash, checkout, reset, switch, commit, push를 하지 않는다. 담당마다 포트 범위를 나누고 `lsof`로 확인하며 하위 에이전트는 띄우지 않는다. 사용된 포트: 9700~9760(태스크 리뷰), 9840~9855(D3c-4 확인), 9900~9919(α 묶음 리뷰). 8765는 사용자 앱이 쓸 수 있어 쓰지 않는다.
- 변형 실험은 `PYTHONDONTWRITEBYTECODE=1`로 돌리거나 끝난 뒤 프로젝트의 `__pycache__`를 지운다(`.venv` 안은 건드리지 않는다).
- Vite 개발 서버는 `host: "127.0.0.1"`을 명시한다(기본이 IPv6 `::1`로만 열린다). 임시 설정 파일은 실험 뒤 지운다.
