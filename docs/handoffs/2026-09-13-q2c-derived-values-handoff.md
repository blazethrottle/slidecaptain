## 목적과 승인 범위

사용자의 개발 재개 요청에 따라 차이/증감률, 계산 불가 사유와 저장/생성/화면의 최소 경로를 진행했다. 회사 자료를 사용하지 않았으며 실제 AI 호출, 자료 외부 전송, 배포, 커밋/푸시는 수행하지 않았다. 사용 중인 앱 서버는 재시작하지 않았다. 임시 검수 서버에는 실제 AI 프로바이더를 연결하지 않았고 검수 후 서버와 생성한 Chrome 탭을 종료했다.

브랜치는 `codex/phase-5b`, HEAD는 `acff346`, 원격은 `https://github.com/blazethrottle/slidecaptain.git`이다. 기존 Q1a/Q2a/Q2b의 미커밋/미추적 변경과 빈 스테이징을 보존했다. 작업 트리가 깨끗하지 않아 pull/브랜치 전환/머지는 하지 않았다. 기존 파일 190개를 작업 전 사본과 대조했다. 이번 단위에서 함께 수정한 18개 외 172개는 변경 0개이며 삭제 0개다.

## 완료한 동작

1. `derivations`에 id/comparison_id/operation을 받는다. 비교의 왼쪽은 대상값, 오른쪽은 기준값이다. 차이와 기준 대비 증감률을 코드가 계산하며 임의 수식, 상수와 연쇄 계산은 받지 않는다.
2. Q2b 비교 조건 일치, 원문의 완전한 숫자 표기, 단위/분모와 양수 기준을 검사한다. 기간 증감률은 대상이 기준보다 뒤여야 한다. 비교 불가/정보 부족, 0/음수 기준, 모호한 값은 숫자를 만들지 않고 사유를 반환한다. 계산 실패는 정상 결과이므로 외부 호출 재시도를 만들지 않는다.
3. `%` 비율의 차이는 퍼센트포인트로 반환한다. 정확한 유리수 산술 후 소수 최대 6자리 ROUND_HALF_UP으로 표시하고 반올림 여부를 남긴다. 숫자는 문자열로 전달해 프런트의 부동소수점 변환을 피한다.
4. `derived_values`는 모델이 생성하지 않는다. API/저장 파일을 읽을 때도 입력에서 재계산한다. 변경된 원문/산식/조건은 보존하지만 기존 fingerprint로 장 생성/축약을 요청하면 호출 전에 409로 거절한다. 실제 변경 전 q2a/q2b 저장본의 fingerprint를 보존하고 신규 계획은 q2c-v1, Deck 버전은 1이다.
5. 계산 결과/반올림/불가 사유를 승인 저장, 재열기, 스냅샷 복원, 편집/undo/redo, 장 생성과 축약으로 전달한다. 기존 수치 존재 경고에는 해당 장 또는 핵심 답변에 연결된 computed 값만 추가한다. 실패 결과나 다른 장에만 연결된 계산은 허용하지 않는다.
6. 화면에 주장, 대상/기준값, 원문 위치, 산식, 값/단위, 반올림과 구체적 사유를 표시한다. 등록된 산식 0건과 대응 결과 부재는 미계산으로 표시한다.

정확한 지원 범위와 숫자 파싱 상한은 [Q2c 실제 계약](../architecture/2026-09-12-quality-pipeline.md), 구현 전 반증 검토는 [단위 계획](../plans/2026-09-13-q2c-derived-values.md)에 있다.

## 미완료와 재심할 전제

- 원문 숫자/위치의 형식 검사가 값과 지표의 의미 연결, 모델이 추출한 메타데이터의 진실성, 산식 선택의 타당성과 비교/계산 등록의 완전성을 입증하지 않는다. 일반 자연어 숫자 해석기나 의미 검수기로 사용하면 안 된다.
- 단위/통화 환산, 회계연도/이동 기간, 표본의 통계적 비교, 비율의 상대 증감률, 임의/연쇄 계산과 분모 수치 재계산은 미지원이다.
- 장 생성/축약에 결과를 전달해도 생성 문장의 부호/단위/대상/기준/반올림과 원문 의미가 맞는지 독립 검수하지 않는다. 기존 수치 경고는 숫자 존재 검사다. Q1a 품질 기록의 의미/근거/시각 검수는 계속 not_run이며 제출본 관문도 유지한다.
- 실제 제공자의 q2c 스키마 수용성, 호출 비용/지연과 보고 품질은 모의 제공자로 입증되지 않는다. 실제 AI 실증 전에 합성 자료 범위와 호출 수를 확인한다.
- Q1b의 검수 상세/이력/무효화와 공통 내보내기 잠금, Q2 요약 정합성/부분 재계획/수동 주장 편집, Q3~Q5는 미완료다. 상위 로드맵에도 이월했다.
