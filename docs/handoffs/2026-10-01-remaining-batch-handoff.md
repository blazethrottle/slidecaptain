LUNA `gpt-6-luna` 실제 호출 **12/12**: 서로 다른 합성 업무 3개 × 일반/기존/개선 생성 9회 + 익명 별도 비평 3회. 실패/형식 재시도 0. 비용 미확인. 후보 9개와 각 버전으로 출력한 PPTX 9개를 보존했다. 범위는 보존 표지·도식과 일반 본문 한 장이며 전체 보고서 품질 통과를 주장하지 않는다. AI 비평은 물류에서 일반+기존 동률, 영업·설문에서는 일반을 선호했다. 개선 우세를 입증하지 않았으며 원자료 조건과 비교 불가 표현의 과도한 단정을 후속 품질 과제로 남긴다.

## 남은 실행과 제약

1. 최신 Windows PowerPoint가 설치된 실제 PC에서 출력 전체 페이지의 렌더·열기·편집과 실제 표시를 검수해야 한다. 현재 Mac에는 PowerPoint가 없다. 어댑터는 실제 실행된 version/build를 기록하지만 최신 설치본이라는 보증이나 업데이트 설치를 대신하지 않는다.
2. 독립 검수자의 신뢰 키 등록과 실제 서명 영수증, 다섯 품질 기준/전체 페이지 판정이 필요하다. Q4a 수동 통과와 AI 비평은 독립 서명이나 제출 승인으로 승격하지 않는다. 현재 제출은 차단 상태다.
3. Q5의 사람 평가·최저 품질 페이지·수정 시간과 새로운 자료/경계 사례의 반복 검증이 남는다. DB-8 AI 표현 선택과 전체 보고서 이해도 향상도 아직 입증하지 않았다.
4. 휴리스틱의 의미 승인, 임의 기간/통계/산식, 자동 근거 의미 동등성 판단, 같은 자료의 여러 stale 근거 일괄 이동, 보호 장 삭제와 임의 복합 배치는 지원하지 않는다. 제한된 수정은 보고 계획 후보 범위이며 보고서 본문 전체의 무인 수정·제출까지 확대하지 않는다.
5. 게시 과정의 private staging은 안전을 위해 자동 삭제하지 않아 공간이 누적된다. 소유권 확인 청소 도구는 아직 없다. 전체 로컬 store+trust rollback은 현재 로컬 신뢰 경계 밖이다.

다음 재개는 원본 Git 상태와 이 인계, 최신 QA를 먼저 대조한다. Windows/사람 입력 없이 통과 기록을 만들지 않으며 새 실호출에는 남은 승인 예산이 없다. 현재 확인된 독립 리뷰 차단 사항은 없다.
