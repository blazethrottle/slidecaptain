# 개정판 D1 독립 앱 기반과 기술 검증

2026-10-02 사용자 시안 검토 후 계속 진행 요청으로 [D1 계획](../plans/2026-10-02-revision-d1-technical-spike.md)을 구현했다.
**Linux 개발/자체 포함 앱 실행은 검증했다. D1 전체 관문은 양 OS 인증/실행 증거가 남아 조건부다.**
기존 `feat/windows-feedback-revision` 미커밋 변경을 보존했다. D1 구현/검증 시점에는 커밋/푸시/배포와 실제 생성 호출을 하지 않았다. 이후 사용자 요청에 따른 Git 반영 여부는 저장소 이력을 따른다.

## 구현과 검증

- Electron 전용 창, 제한된 preload, 공식 로그인 URL 열기, 파일/폴더 선택 후 즉시 읽기, API 전송/취소를 구현했다.
- Python이 자신의 loopback 포트 0 소켓을 직접 바인딩한다. 제품/버전/실행 ID/UI 준비를 확인하고 실행별 세션은 main/서비스만 보유한다. renderer·명령행·로그에 반환하지 않는다.
- OpenAPI와 일치하는 38개 경로/메서드와 허용 헤더/본문으로 main API를 제한한다. 기존 AI 동의/선택/ETag와 서버 보호를 유지한다. 브라우저/독립 앱에서 같은 클라이언트를 사용한다.
- 원본 파일을 변경하지 않고 일반 파일/링크/열린 핸들 identity/읽기 중 변경을 확인한다. 100개/개별 20MB/총 40MB와 부분 실패를 적용한다. 폴더는 바로 아래 문서만 읽고 항목 1,000개를 제한한다.
- 부모 stdin EOF를 감지한다. 정리가 잠금에서 지연되는 반례도 private POSIX process group/Windows Job Object로 소유 자식을 정리한다. Linux의 지연 정리+합성 자식 종료는 독립 재현으로 확인했다.
- 미저장/진행 중 작업의 종료 결정을 창에서 먼저 처리하고 승인된 종료에서 service 정리 후 main을 종료한다. 반복 종료도 완료를 기다린다.
- `scripts/build_desktop_service.py`가 호스트 OS용 Python/UI/폰트/메트릭 서비스와 SHA-256 manifest를 만든다. 공식 CLI·계정·사용자 자료는 포함하지 않는다.
- `desktop/builder.cjs`에서 서비스/출력 절대 경로를 빌드 전에 해석한다. 최초 builder 환경 변수 매크로가 절대 경로를 상대 경로로 오해해 서비스가 누락된 실측 문제를 수정했다. 수정 후 실제 서비스를 포함한 앱으로 외부 Python 없이 실행했다.
- Windows/macOS CI에 서비스 패키징/frozen smoke/미서명 앱 패키지를 추가했다. 실행 결과 없이 두 OS 통과나 서명/공증 완료를 주장하지 않는다.

## 공식 AI 지원 조사

`PYTHONPATH=backend backend/.venv/bin/python scripts/probe_ai_capabilities.py --out <체크아웃 밖 새 파일>`로 재현한다.
SDK 초기화와 Codex `model/list`만 사용한다. 별도 최소 환경 프로세스로 기존 API/OAuth 환경을 제외하고 임시 빈 프로필을 폐기한다. 원시 응답/계정/토큰은 저장하지 않는다. OS 자격 증명 저장소의 격리와 실제 로그인 프로필 2개 전환은 미검증이다. 카탈로그 존재는 구독 호출 권한/성능 증거가 아니다.

사용자 지정 [Claude 테스트 저장소](https://github.com/blazethrottle/modeltest-claudecode)의 기준 커밋 `b68b2bd7c917a62cc1d243ac338060ee2d41cf0d` 가이드는 5.5 계열이다. 이번 카탈로그의 5 계열과 버전이 달라 성능 순위를 자동 적용할 수 없다. D4 추천은 동일 실제 ID/검증 범위가 확인된 경우만 연결한다. 추천 상세 보기 제거와 ChatGPT 추천 후속 요청은 유지한다.

공식 SDK 소스 `anthropics/claude-agent-sdk-python` 조사 커밋 `bfb895c6ef46e095191938b4eda798a025957c09`에서 `CLAUDE_CONFIG_DIR`와 macOS Keychain 식별의 경로 연동을 확인했다. 인증 파일 복사 예제는 도입하지 않는다. Codex는 공식 `CODEX_HOME`을 프로필별로 지정할 수 있다. Windows/macOS에서 서로 다른 로그인 계정 2개 전환은 미검증이다. 현재 제품의 Claude 단일 프로필/별칭 어댑터와 Effort 미전달은 D4 변경 대상이다. Google은 제공자의 공식 브라우저 로그인에서 선택하며 앱 자체 인증키나 비밀번호 입력을 추가하지 않는다.
