# 새 도식 AI 후보 생성과 로컬 QA 완료

작성: 2026-09-29. 개발 및 QA 재개 요청으로 [직전 인계](2026-09-29-story-rewrite-edits-handoff.md) 이후 Q3b의 새 도식 AI 초안을 연결했다. [계획](../plans/2026-09-29-diagram-ai-draft.md), [검증 기록](../qa/2026-09-29-diagram-ai-draft.md).

## 사용할 수 있는 흐름

편집 화면에서 도식 추가 → 제목/보고 역할/기존 주장 선택 → AI 도식 초안 생성 → 후보 검토 → 작성 폼에 불러오기 → 입력과 배치 확인 → 도식 적용으로 진행한다. 현재 선택한 제공자/모델과 전송 동의를 사용하며 자동으로 다른 제공자를 선택하지 않는다.

AI는 선택한 주장과 근거 발췌로 nodes/edges만 출력한다. 서버가 도식 ID/버전/캔버스를 만들고 허용 근거와 구조를 검사한다. 새 주장/근거 생성이나 기존 도식 교체는 제공하지 않는다. 구조상 유효해도 배치가 불가능하면 기존 검사에서 거절하고 입력을 보존한다. 생성 후보는 의미/제출 품질 검수를 통과한 결과가 아니다.

생성 전후와 제공자 lease 획득 후 ETag/전체 자료를 재확인한다. 후보 생성과 불러오기는 저장하지 않는다. 편집/닫힘/충돌/늦은 응답에서 기존 덱을 보호하고 요청 완료까지 모델 변경 잠금을 유지한다. 형식 재시도는 최대 1회이며 usage의 결측은 미확인으로 유지한다.

## 구현과 검증

- 백엔드: `pipeline/diagram_generation.py`, `pipeline/service.py`, `server/app.py`. 새 API는 `POST /api/projects/{name}/generate/diagram`이다. OpenAPI/TypeScript도 함께 갱신했다.
- 프런트: 도식 작성창의 후보 검토/불러오기, 호출 잠금의 프로젝트 배선, 동의창 표시/고지/포커스, 1000px 이하 편집기의 한 열 배치.
- 백엔드 전체 1,710개 통과/Windows 전용 1개 미실행, 프런트 434개, 타입/빌드와 생성 계약 왕복, HTTP/PPTX 22개와 Chrome 합성 관통을 확인했다. 독립 리뷰 필수 잔여는 0건이다.
- 계획 리뷰의 동의창 가림/고지 누락, 구현 리뷰의 포커스 복귀, Chrome의 480px 미리보기 폭 0 문제를 해소했다. 480px↔1440px의 실제 크기 변경과 하단 포함성을 확인했다.

구현과 독립 검토의 역할을 나누고 반례로 검증하는 절차를 적용했다. [[wiki:Implementer-Reviewer-Applier-Pipeline]] 사용자 품질 판정은 수행하거나 추정하지 않았다. 새 위키 본문은 만들지 않았다.
