## 변경한 동작

AI에게 보호 도식의 연결, 주장, 근거의 null 값, 비교와 산식을 다시 쓰도록 요구하던 계약을 바꿨다. 이제 AI는 `chapter_order`에 전체 장 순서를 제안하고 `chapters`에는 보호 도식 외의 장 연결만 반환한다. 다른 목록에도 보호되지 않은 항목만 출력한다. 보호된 그래프는 서버가 현재 저장본에서 가져온다.

보호 ID를 재출력하면 동일한 내용도 거절한다. 보호 주장에 새 비교를 붙이거나 보호 비교에 새 산식을 붙이는 우회도 거절한다. 일반 주장이 보호 근거를 참조해 새 비교/산식을 만드는 것은 허용한다. 중복 ID, 미연결 주장과 핵심 답변의 역할 불일치를 임의로 정리하지 않고 기존 검사를 적용한다.

보호 범위에는 도식 노드/간선의 직접 근거도 포함된다. 원문 해시/위치/발췌, 미리보기 무저장, 적용 시 ETag/전체 자료 식별값, 기존 본문과 도식의 보존 검사는 유지한다. API/저장/OpenAPI/프런트 타입은 바꾸지 않았고 AI 전용 응답과 오프라인 고정 응답만 새 계약으로 맞췄다.

## 실제 LUNA 결과

사용자가 이번 실행에 총 3회를 새로 승인했다. 동일한 합성 3장 자료를 `gpt-6-luna`로 실행해 장 생성 1회, 재작성 1회, 형식 재시도 1회로 완료했다. 기존 승인 5회와 별도이며 이번 3회도 모두 소진했다. 추가 실제 호출은 남은 예산이 없다.

첫 재작성은 보호 필드를 재출력하지 않았으나 action 장에만 연결된 주장을 `answer_claim_ids`에도 넣어 거절됐다. 재시도는 해당 연결을 수정해 정상 후보를 반환했다. 이 경계를 API 회귀로 추가했다. 한 합성 사례의 재시도 포함 성공이며 LUNA가 항상 첫 시도에 성공하거나 다른 모델보다 낫다는 결과가 아니다.

후보 미리보기의 무저장, 적용 후 본문/도식/보호 근거 보존, 3장 PPTX 재열기, 편집 가능한 도식 도형, PPTX/품질 기록 해시와 미검수 제출본 거절을 확인했다. 출력 상태는 `draft`다. 이번 화면 검수, 실제 PowerPoint 표시/편집, 독립 의미 검수와 독자 품질 판정은 수행하지 않았다.
