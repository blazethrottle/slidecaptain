## 3. D3c-6 리뷰 반영의 요점 (`378e84c`)

- 반영 요청은 미리 보기의 기준 저장본(`base_etag`)을 `If-Match`로 보내고, 마지막 미리 보기가 돌려준 실제 선택을 보낸다. 비교 화면이 열린 동안 편집기 단축키는 막힌다(모달 검사).
- 요청에 `edit_choices`(사용자가 건드린 요소 수정만)를 더했다. 건드리지 않은 요소 수정은 서버가 지금 선택으로 기본값을 다시 계산한다. 이것은 계획 4.8에 없던 API 확장이다.
- 초점 가두기는 라디오 묶음을 정지점 하나로 센다. 실제 브라우저에서 Shift+Tab이 대화 상자 밖으로 나가지 않음을 확인했다(`~/Projects/slidecaptain-work/d3c6-fix/browser-fix.json`).
- 차이 요약에 디자인 값, 문서 검토 기록, 저장본 읽기 실패를 더했다.
- 변형 41개를 모두 시험이 잡는다(`~/Projects/slidecaptain-work/d3c6-fix/mutate.py`).
- 결정으로 남긴 것: 구성 화면 412는 초안을 보존본으로 남기지 않고 부모 배너만 띄운다(G14). 서버의 보존본 복원 라우트는 묶음 실행 중에도 막지 않고, 화면 잠금만 가드다(G20). 미리 보기의 덱 전체 렌더 두 번(G17)은 D3c-8에서 잰다.
