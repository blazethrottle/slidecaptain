# Q2c: 근거와 산식을 연결한 결정론 계산

작성: 2026-09-13. 최신 Q2b 인계의 다음 개발 단위를 이어받는다. 기존 Q1a/Q2a/Q2b 변경을 보존하고 합성 자료로 구현, 테스트와 빌드까지 수행한다.

## 범위와 계약

- `derivations`에는 id, comparison_id, operation(difference/percent_change)만 받는다. Q2b 비교의 왼쪽은 대상값, 오른쪽은 기준값이다. 차이는 대상값 - 기준값, 증감률은 (대상값 - 기준값) / 기준값 × 100이다. 임의 수식, 상수, 계산 결과와 연쇄 계산은 받지 않는다.
- Q2b 비교 조건이 일치해야 계산한다. 증감률의 기준값은 양수여야 하며, 기간 비교에서는 대상 기간이 기준 기간보다 뒤여야 한다. 비교 불가/정보 부족은 숫자 결과로 대체하지 않는다.
- 원문 `value` 전체를 읽는다. ASCII 부호, 정수/소수, 올바른 3자리 쉼표와 비교 계약에 일치하는 단위 접미사를 지원한다. 숫자는 최대 24자리(소수 최대 6자리), 값 문자열은 최대 128자다. 지수, 범위, '약'이 붙은 값, 회계 괄호, 복합 한국어 수와 모호한 숫자 일부 선택은 계산 불가다. 원문과 값의 의미 일치 검수까지 수행한 것으로 표시하지 않는다.
- 분모가 해당 없음인 절대값의 차이와 증감률을 지원한다. 모집단이 선언된 `%` 비율의 차이는 퍼센트포인트로 반환한다. 비율의 상대 증감률, 단위 환산과 분모 수치의 재계산은 후속 범위다.
- `derived_values`는 코드가 생성하며 저장/API 입력을 읽을 때 재계산한다. 결과에는 산식, 값/단위, 반올림 여부와 계산 불가 사유가 있다. 정밀 계산 후 소수 최대 6자리, ROUND_HALF_UP으로 표시하고 반올림을 명시한다.
- 새 계획은 q2c-v1이다. Deck 버전 1과 실제 q2a/q2b 저장본의 fingerprint를 유지한다. 이전 버전에 계산 필드를 숨기는 입력은 거절한다. 원문/산식/비교 입력이 달라지면 기존 계획으로 장 생성과 축약을 요청할 때 기존 409 경로로 차단한다.
- 승인/저장/재읽기/복원/편집/장 생성/축약/화면을 잇는다. 계산 대상 0건은 미검사다. 생성된 문장의 숫자와 계산 결과가 일치하는지 독립 검수하는 것은 후속 범위다.

## 구현 전 반증 검토

0과 결측, 퍼센트와 퍼센트포인트, 음수 기준에서의 역전, 분모/단위 불일치, 원문 120에서 20만 고르는 부분 숫자, 부동소수점 오차, 반올림 뒤 -0, 파일의 위조된 성공 결과와 새 기본 필드에 의한 옛 계획 만료를 실패 사례로 검증한다. 계산 실패는 정상 결과이며 외부 호출 재시도를 만들지 않는다. 없는 참조/중복 ID/임의 산식은 기존 형식 오류 재시도 최대 1회로 끝낸다.

`engineering:code-review` 기준으로 자체 검토한다. 설치 검색에서 superpowers와 requesting-code-review는 각 0건이다. 독립 에이전트 검토는 수행하지 않는다. 자동화 검증을 실제 AI 수용성, PowerPoint 표시나 독자 품질 평가로 대신하지 않는다.

## 완료 조건

계산과 실패 경계, 기존 저장본 호환, 결과 재계산, 저장/API/생성 문맥/프런트 편집 보존을 검증한다. OpenAPI/TypeScript, 전체 회귀와 빌드를 확인하고 실제 계약/로드맵/인계를 갱신한다. 실제 AI 호출과 자료 전송, 사용 중 앱 재시작, 커밋/푸시/배포는 이번 단위에서 수행하지 않는다.

## 실행 결과

백엔드 전체 1,108개 중 실패 0개, 프런트 전체 275개 중 실패 0개(26개 파일), tsc/Vite 빌드와 OpenAPI/생성 TypeScript 대조를 통과했다. 새 회귀는 백엔드 75개와 프런트 10개다. 실제 Chrome에서 합성 자료의 정상 계산/계산 불가/반올림 3개 사례를 확인했다. 임시 서버/생성한 탭은 검수 후 종료했다.

자체 검토와 화면 검수에서 숫자 일부/공백 뒤 다른 단위 허용, 구두점 오거절, 생성 지침 충돌과 계산 불가 안내 문구를 수정했다. 옛 두 저장본의 fingerprint와 백엔드/프런트 공유 합성 저장본의 왕복을 확인했다. 미완료와 재심할 전제, 다음 수치/문장 정합성 검수는 상위 로드맵과 [Q2c 인계](../handoffs/2026-09-13-q2c-derived-values-handoff.md)에 반영했다. 실제 AI/PowerPoint/독자 평가와 독립 에이전트 검토는 미수행이다.
