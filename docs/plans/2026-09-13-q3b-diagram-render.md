# Q3b 두 번째 단위: 미리보기와 편집 가능한 PPTX

작성: 2026-09-13. 사용자 요청은 SlideCaptain 개발 계속 진행이다. 최신 배치 인계의 다음 단위를 구현한다. 원본 파일 244개와 빈 스테이징을 보존하며 별도 작업 트리에서 검증한다.

## 목적과 종료 지점

원래 DiagramSpec, Evidence, Preset와 폰트 수치에서 재계산한 도식 한 페이지를 기존 Preview와 PPTX 라이터가 함께 소비한다. 제목, 분류 라벨, 부제와 각주의 예약 영역을 공통 기하 계산에 맞춘다. 도형과 텍스트는 편집 가능한 PowerPoint 객체로 기록한다. 자동 생성, 프로젝트의 도식 저장/편집, 새 API/CLI, 제출본 승인과 실제 AI 호출은 이번 단위에 포함하지 않는다.

## 계약과 전제

1. `build_diagram_render_plan`은 원래 의미 입력을 매번 재검증한다. 직렬화된 배치나 computed 상태를 입력으로 신뢰하지 않는다. 배치와 공통 텍스트 중 하나라도 불가하면 항목별 typed issue를 담은 예외를 반환하며 부분 RenderPlan을 반환하지 않는다. 저장소 파일을 읽거나 변경하지 않는다.
2. 배치 계산기에 분류 라벨과 부제를 전달하고 기존 `slide_geometry`를 재사용한다. 지원하지 않는 공백/글리프, 제목/각주의 높이 초과와 페이지 밖 공통 텍스트도 차단한다. 내용 삭제나 글자 축소는 하지 않는다. 기존 인자가 없는 Q3b 계산은 유지한다.
3. `SlidePlan.diagram`은 선택적인 출력 전용 필드다. 도식 배치, 공통 Frame, 배경색, 입력 fingerprint와 not_run 검수 상태를 담는다. 기존 Deck/StoryPlan/저장 버전은 바꾸지 않는다. 출력 스키마와 OpenAPI/생성 TypeScript는 함께 갱신한다.
4. Preview는 새 읽기 전용 도식 레이어를 그린다. 좌표/크기/줄바꿈은 백엔드 결과 그대로이며, 선은 SVG, 텍스트는 고정 줄 높이와 명시적 줄바꿈으로 표시한다. 노드/관계/근거 ID를 보존한다. 이 레이어에서 기존 슬롯 편집 콜백을 호출하지 않는다.
5. PPTX는 노드 사각형, 텍스트 상자, 선과 삼각형 화살표를 각각 편집 가능한 객체로 만든다. 글자 자동 맞춤과 자동 줄바꿈을 끄고 계산된 줄을 기록한다. 모든 문단의 행간/앞뒤 간격과 한글/영문 폰트를 명시한다. 역할 이름과 대체 설명에 의미 ID/근거 연결을 기록하며 임의 HTML/스크립트를 실행하지 않는다.
6. 점선/파선의 길이와 간격은 백엔드가 pt로 계산한다. Preview의 dash 배열과 PPTX의 custom dash는 같은 값을 소비한다. 화살표는 계산된 점을 사용하며 소비자가 삼각형 크기나 방향을 재결정하지 않는다.
7. 기존 일반 RenderPlan 작성 경로와 자동 줄바꿈은 유지한다. 새 도식의 low-level 소비자는 내부 계산 결과만 받는 경계다. 외부 저장본에서 RenderPlan을 받아 제출본으로 내보내는 API를 추가하지 않는다. 실제 브라우저, PowerPoint, 독자 검수 여부를 별도 기록하며 computed는 품질 승인이 아니다.

## 검증

- 구현 전 실패 검사: 공통 슬롯 공간 분리, 원본/근거/조건/방향 보존, 넘침 차단과 입력 재검증, 동일 입력 결정론과 fingerprint 변화.
- 합성 fixture 하나의 실제 백엔드 RenderPlan을 프런트와 PPTX 재열기 검사가 함께 사용한다. 좌표/줄바꿈/폰트/선/화살표 점과 의미 태그를 대조하고 기존 템플릿 회귀를 검사한다.
- 문구에 HTML 특수문자, 줄바꿈과 빈 줄, 참조/제안 역방향과 복수 레인을 포함한다. 실제 브라우저 표시를 가능한 도구로 확인한다. PPTX XML과 재열기는 목표 PowerPoint 표시 검증으로 보고하지 않는다.
- 백엔드/프런트 전체 검사, 타입 재생성, 빌드와 공개 파일 감사, 저장본 왕복 및 원본 보존을 확인한다. 계획과 구현은 독립 검토를 거친다.

## 계획 독립 검토 반영 (2026-09-13)

전체 페이지 fingerprint에 제목/분류 라벨/부제/각주/페이지 번호를 각각 포함한다. 페이지 번호는 기존 공통 기하와 크기를 재사용한다. 모든 공통 영역 쌍과 도식 본문 영역의 겹침, 페이지 밖 위치도 차단한다.

노드 bounds는 테두리 중심선이며 Preview에서 SVG rect로 그린다. 관계선은 SVG butt와 OOXML flat을 명시하고 삼각형 화살표는 채움만 그린다. dash pt를 OOXML 선 굵기 대비 비율로 바꾸고 재열기에서는 pt로 역산해 대조한다. [Microsoft DashStop 명세](https://learn.microsoft.com/en-us/dotnet/api/documentformat.openxml.drawing.dashstop?view=openxml-3.0.1)를 확인했다. 도식 텍스트는 공통 header까지 fixed-lines 소비자를 사용하며 일반 프레임은 바꾸지 않는다. 브라우저 검사에서는 실제 regular/bold 글꼴 로드 여부를 별도로 확인한다.

## 구현 검토 반영과 검증 (2026-09-13)

공통 슬롯의 overflow, 현재 python-pptx의 페이지/글자/행간 표현 범위와 0EMU 선 굵기를 실패 재현 뒤 typed blocked로 처리했다. 고정 행간은 0.01pt 정수로 반올림해 부동소수점 절단을 피한다. 기존 preflight-v2 식별값은 비어 있는 새 diagram만 제외해 유지한다. 마지막 독립 재검토의 남은 필수 수정은 0개다. 실제 Chrome 합성 3개와 번들 폰트 2개 로드, PPTX 구조/편집 왕복, 전체 검사와 미검증 범위는 [완료 인계](../handoffs/2026-09-13-q3b-diagram-render-handoff.md)에 기록했다.
