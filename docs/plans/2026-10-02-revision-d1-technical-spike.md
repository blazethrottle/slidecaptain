# 개정판 D1 기술 검증 및 독립 앱 기반

2026-10-02: 사용자가 10종 대표 페이지와 직접 수정 시안을 검토한 뒤 계속 진행을 지시했다. 시안 검토 단계에서 구현 단계로 전환한다. [전체 기술 설계](../architecture/2026-10-02-desktop-revision.md)의 D1을 먼저 실행하고 결과로 후속 계약을 확정한다. 기존 작업 브랜치와 미커밋 변경은 보존한다.

## 이번 단위

1. Electron 전용 창과 기존 Python 서비스의 실행/준비/종료를 연결한다. 서비스가 직접 빈 포트의 소켓을 확보하고 실행별 인증을 사용한다. 다른 기존 서버에 붙거나 다른 프로세스를 종료하지 않는다.
2. 앱 창의 Node 접근을 끄고 제한된 파일/폴더 선택과 공식 로그인 URL 열기만 preload로 제공한다. 원본 파일은 읽기만 하며 비정상 파일/과대 파일은 거절한다.
3. 개발 실행과 호스트 OS별 자체 포함 Python 서비스 빌드 경로를 만든다. Windows/macOS 패키징 절차는 같은 계약으로 관리한다. Linux 클라우드 실행을 양 OS 실기기 통과로 기록하지 않는다.
4. 공식 Claude SDK의 초기화와 Codex model/list로 모델 ID/지원 Effort를 생성 호출 없이 조사한다. 출처·조회 범위·계정 사용 가능 여부를 구분한다. 다중 계정은 공식 경로와 OS별 인증 저장 범위를 확인하고 미확인 부분을 남긴다.
5. HWP/HWPX 추출 후보의 라이선스와 텍스트/원문 위치 지원을 비교하고 합성 사례에서 검증한다. 라이선스 또는 지원 범위가 맞지 않는 후보를 편의상 제품 기본값으로 확정하지 않는다.

## 수용 기준

- 시작 실패/시간 초과/서비스 종료, 세션 인증 누락/불일치, 기존 웹 모드 호환, 준비 응답의 제품/버전/실행 식별자, 잘못된 IPC 발신자/외부 탐색을 검사한다.
- 개발 앱에서 합성 프로젝트 저장/재열기/초안 PPTX까지 확인한다. 서비스 종료 후 자신의 자원만 정리됨을 확인한다.
- 자체 포함 서비스는 UI/메트릭/폰트/동적 모듈을 포함하고 사용자 프로젝트/인증정보를 포함하지 않는다. 공식 CLI 재배포가 확정되지 않으면 CLI 자체는 외부 공식 설치 경로를 사용한다.
- 모델 조회는 원시 계정/토큰을 저장하거나 출력하지 않는다. 모델 카탈로그를 실제 호출 권한이나 추천 가이드의 버전 일치로 간주하지 않는다. 실제 생성 호출은 이 기술 검증에 필요하지 않다.
- 독립 계획/코드 검토, 관련 백엔드/desktop 테스트, 프런트 빌드, 공개 저장소 감사와 실제 Linux 클라우드 실행을 기록한다.

Windows/macOS의 실제 로그인·두 계정 전환·설치·서명/공증·PowerPoint 검증은 해당 OS의 실행 증거가 필요하다. 클라우드에서 가능한 계약과 빌드/실행 검증을 먼저 완료하며 미확인 경계를 명시한다.

## 독립 계획 검토 반영

2026-10-02: 세 가지 반례를 계약에 추가했다. API는 OpenAPI에서 생성한 경로/메서드 목록과 허용 헤더·20MB 본문 상한으로 main에서 검증하며 인증값은 main의 메모리와 자식의 초기 환경에서만 사용한다. renderer에는 인증값을 반환하지 않고 준비/로그/명령행에도 넣지 않는다. 파일은 선택과 읽기를 같은 main 작업에서 완료해 경로를 renderer로 받지 않으며 일반 파일/심볼릭 링크/identity/크기/읽기 중 변경을 확인한다. 폴더는 파일 100개·개별 20MB·총 40MB·폴더 항목 1,000개 상한과 부분 실패를 적용한다. 서비스는 부모의 stdin 파이프 EOF로 main 강제 종료를 감지해 종료하고, 제한 시간 이후 자신의 서비스와 소유 자식의 프로세스 경계를 정리한다. 기존 서버가 계속 살아 있는지를 실행 검증에 추가한다.
