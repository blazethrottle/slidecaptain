## 2. 지금 코드에서 확인한 사실 (기준 `e57853a`)

1. `export/pptx_writer.py` `_add_chart_shape`는 `major_unit=axis_maximum/5`를 쓰고, python-pptx 기본값으로 값 축 주 눈금선(`c:majorGridlines`)이 켜진다.
2. `layout/expression.py` `axis_maximum_text`는 다섯 눈금(최댓값의 k/5)을 모두 정확히 보일 소수 자릿수를 남긴다. 그래서 bar15의 축 최댓값이 `135802468.035810`(6자리)이다.
3. `ChartPoint.value`는 원문 값 문자열이고, 미리보기(`frontend/src/editor/ChartPreview.tsx`)와 PPTX 라벨 서식(`_number_format`)이 모두 이 글자의 자릿수를 따른다.
4. 미리보기는 0과 최댓값만 그린다. 가로 막대는 둘 다 `y0+font` 기준선에, 0은 시작 맞춤, 최댓값은 끝 맞춤이다. 세로 막대도 0을 그림 영역 아래 `y0+font`에, 최댓값을 그림 영역 왼쪽 `plot_y` 기준선에 그린다.
5. 회사 PC PowerPoint(16.0 build 20430)는 '0.00' 서식에서 1.005, 2.675, 0.125, 123456789.125를 1.01, 2.68, 0.13, 123456789.13으로 보였다(2026-10-20 실측, 표본 12개). 원문 값을 float로 넣어도 Decimal의 ROUND_HALF_UP과 같은 글자다.

## 3. 설계

### 3.1 표시 글자 (18)

`ChartPoint`에 표시 글자 `display`를 더한다. 레이아웃이 원문 Decimal에서 계산한다(소수 3자리 이상이면 `quantize(0.01, ROUND_HALF_UP)`). 미리보기는 `display`를 그리고, 레이아웃의 값 글자 폭도 `display`로 잰다. PPTX는 내장 데이터에 원문 값을 넣고, 라벨 서식을 `display`의 자릿수로 정한다(2절 5의 실측 근거). 내장 워크북 칸의 서식은 원문 자릿수를 따른다(2판, 리뷰 CDR-01).

축 최댓값은 `max(값)*1.1`을 소수 2자리로 올림한다. 눈금이 0과 최댓값 둘뿐이므로(3.2) 최댓값 자체의 자릿수만 남긴다. 값이 1조 이하라 최댓값은 정수 13자리와 소수 2자리, 15자리 안이다.

### 3.2 PowerPoint 눈금 (16)

값 축의 주 눈금선을 끄고 주 단위를 최댓값으로 둔다. 축 서식은 최댓값 글자의 자릿수를 따른다(0 눈금은 지금처럼 '0').

### 3.3 미리보기 축 글자 위치 (16)

PowerPoint에서 바뀐 차트를 렌더해 0과 최댓값 글자의 획 위치를 잰다. 미리보기 글자의 획 위치를 Noto Sans KR 글리프 경계로 계산해 1pt 안으로 맞춘다. 가로 막대는 기준선과 가로 정렬, 세로 막대는 0 글자를 그림 영역 왼쪽으로 옮기는 것까지 측정값에 따른다.

## 5. 수용 기준

1. 소수 3자리 이상인 차트 값은 미리보기와 PowerPoint에서 같은 소수 2자리 글자로 보이고, PPTX 내장 데이터에는 원문 값이 남는다.
2. PowerPoint 차트에 값 축 눈금선과 중간 눈금 글자가 없다.
3. 0과 최댓값 글자의 획 위치가 PowerPoint와 미리보기에서 1pt 안이다. PowerPoint 쪽은 회사 PC 실측이고, 미리보기 쪽은 번들 글꼴의 글리프 계산값이다(브라우저 화면 대조는 하지 않았다).

5. 백엔드와 프런트 전체 시험, 생성 파일 무변경, CI 두 OS 성공.

## 9. 둘째 사용자 결정 (2026-10-20)

리뷰 반영 뒤 진행 보고에서 네 건을 물었고, 사용자가 다시 "추천대로 승인"으로 답했다. 추천이 기록된 것은 두 건이다.

1. **머지**: 추천 원문은 "A안(추천): GitHub에서 PR #3을 직접 머지하십니다."였다. 사용자가 GitHub에서 머지한다. 세션은 이 브랜치도 같은 방식으로 머지할 수 있게 PR을 연다(PR #3 다음 순서).
2. **(17) 시안 선택**: 보고에 추천을 적지 않았다. 이번 답으로는 정하지 않고, 추천을 붙여 다시 묻는다.
3. **(19) 아이콘 확인**: 질문이라 추천이 없다. 확인 대기를 유지한다.
4. **(20) 15자리 거절 완화**: 추천 원문은 "A안(추천): 지금처럼 거절합니다. PowerPoint 데이터 표에 원래 숫자를 정확히 남기려면 이 제한이 필요합니다."였다. 거절을 유지하고 코드는 바꾸지 않는다.
