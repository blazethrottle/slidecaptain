# 장 제목 28pt와 차트 영역 80% (회사 PC 이월 (17))

작성: 2026-10-20(회사 PC, Windows). 상태: 1판. 브랜치 `feat/title-chart-ratio`(기준 main `6429d39`).

상위 문서: [로드맵](2026-08-27-mvp-roadmap.md) 「진행 상태」의 2026-10-16 회사 PC 확인 이월표 (17), [C3 후속 계획](2026-10-20-c3-followup-chart-display.md) 1절 3, [C3 후속 확인 기록](../qa/2026-10-20-c3-chart-display.md) 5절(시안).

## 1. 사용자 결정과 해석

2026-10-20 사용자 지시: "머지는 네가 직접 실행해줘 (이제까지 그래왔던 것 처럼), 제목 28pt, 차트 80% 로 적용해줘." 사용자는 시안 C(제목 28pt, 차트 영역 80%)의 값을 골랐다. 바로 앞 보고에서 세션이 추천한 시안은 A(24pt, 90%)였으므로, 값은 사용자의 직접 선택이다.

적용 범위는 지시에 없었다. 세션은 바로 앞 보고의 추천 범위를 따랐고, 사용자는 그 추천에 이의를 달지 않았다. 추천 원문: "제목 크기는 모든 템플릿에 적용합니다. 한 덱 안에서 장마다 제목 크기가 다르면 통일감이 깨지기 때문입니다." "차트 영역 비율은 차트가 있는 장에만 적용합니다." "시안처럼 가운데 배치를 추천합니다."

- 장 제목: 기본 프리셋의 `title_pt`를 20에서 28로 바꾼다. 모든 내용 템플릿의 장 제목이 28pt가 된다. 표지 제목(`cover_title_pt` 28)과 섹션 제목(`section_title_pt` 24)은 지시 범위 밖이라 바꾸지 않는다(5절 위계 문제).
- 차트: 비교 차트는 표 자리(내용 영역)의 폭과 높이를 80%로 줄여 가운데에 둔다. 조건 문장은 줄인 영역 안, 차트 바로 아래에 둔다.

## 2. 지금 코드에서 확인한 사실 (기준 `6429d39`)

1. 장 제목은 `layout/templates.py`가 `title_height`(40pt) 칸에 `title_pt`로 그리고, 넘침 경고는 같은 칸으로 판정한다(`_title_warning`). 28pt 한 줄은 행간 1.4배로 39.2pt라 칸 안에 들어간다. 칸 높이와 내용 영역 위치는 바뀌지 않는다.
2. 한 줄 글자 수(본문 폭 860pt, 굵은 한글, 안전 비율 0.97)는 20pt 45자, 28pt 32자다. AI 구성 단계 프롬프트는 장 제목의 글자 수 한도를 받지 않는다. 그래서 32자를 넘는 제목은 앞으로 넘침 경고가 난다. 저장소 표본의 장 제목 54개는 모두 32자 안이다.
3. 디자인 설정은 전역 `preset.json`(프로젝트 루트)과 덱의 `preset_overrides`에 저장된다. 이미 `preset.json`을 저장한 설치는 그 파일의 20pt를 계속 쓰고, 디자인 화면의 "제목 크기(pt)"로 바꿀 수 있다. 이 PC에는 `preset.json`이 없다.
4. 비교 차트는 `layout/engine.py`가 표 프레임 자리에 `build_comparison_chart`로 만든다. 직접 수정은 차트 두 프레임을 표의 열쇠(`table`)로 묶어 옮기므로, 영역을 줄여도 이름과 묶음은 그대로다.

## 3. 설계

- `models/preset.py`: `title_pt` 기본값 28.
- `layout/expression.py`: `CHART_AREA_RATIO = 0.8`, `chart_area(frame)`가 표 프레임의 가운데 80% 영역을 돌려준다. `layout/engine.py`가 이 영역을 `build_comparison_chart`에 준다. `build_comparison_chart` 자체는 받은 틀을 채우는 지금 계약을 유지한다(높이 하한 시험이 그 계약을 쓴다).
- OpenAPI와 프런트 타입은 기본값 문구만 바뀐다.

## 4. 수용 기준

1. 기본 프리셋으로 만든 모든 내용 템플릿의 장 제목이 28pt이고, 제목 칸 높이와 내용 영역 위치는 그대로다.
2. 비교 차트와 조건 문장이 표 자리 가운데 80% 영역 안에 있다. PowerPoint 렌더에서 그림 영역과 막대가 계획과 1pt 안이다.
3. 백엔드와 프런트 전체 시험, 생성 파일 무변경, CI 두 OS 성공.
4. 10종 템플릿 표본을 PowerPoint로 렌더해 제목이 한 줄로 칸 안에 있다.

## 5. 남는 문제 (사용자 결정 대기)

1. 제목 위계: 표지 제목 28pt가 장 제목과 같고, 섹션 제목 24pt는 장 제목보다 작다(2026-10-20 PowerPoint 렌더에서 확인). 표지와 섹션 제목을 키울지 정한다.
2. 장 제목 길이: 한 줄 32자를 넘는 제목은 넘침 경고가 난다. AI 구성 단계에 장 제목 글자 수 한도를 알릴지 정한다.

## 6. 영향

- 모든 덱의 렌더 계획이 바뀐다(장 제목 크기). 차트 덱은 차트 영역도 바뀐다. 업데이트 뒤 기존 내보내기가 "현재 저장본과 다름"으로 표시된다. 로드맵 회사 PC 확인 이월표 (6)과 같은 D4 릴리스 안내에 더한다.
- 32자를 넘는 기존 장 제목에는 넘침 경고가 새로 생긴다.

## 7. 리뷰

범위가 상수 두 개와 배치 함수 하나라 계획 리뷰를 따로 두지 않고, 구현 뒤 리뷰어 1명이 계획과 코드를 함께 본다(C3 후속과 같은 방식).
