# Q2b: 지표 비교 계약과 비교 불가 사유

작성: 2026-09-12. [Q2a 인계](../handoffs/2026-09-12-q2a-story-plan-handoff.md)의 다음 단위를 이어받는다. Q1a/Q2a의 미커밋 변경을 보존하고 합성 자료로 구현, 테스트와 빌드까지 진행한다.

## 범위

- 근거에 선택적 `metric_basis`를 둔다. 지표 정의, 단위, 주체, 기간(시작/끝, 월/분기/연/시점/기타, 집계 방식, 완결 여부), 분모(해당 없음/모집단/미확인과 정의)를 구조화한다. 기존 자유 문자열 메타데이터는 보존하되 비교 판정에 섞지 않는다.
- 계획은 주장 ID, 두 근거 ID와 비교축(entity/period)을 명시한다. 코드가 정의/단위/분모 및 비교축 외 조건을 대조하고 `compatible`, `incompatible`, `insufficient_metadata`와 사유를 반환한다. 같은 주체의 비중첩 완결 월/분기/연 기간 비교와 같은 기간의 주체 비교부터 지원한다. 기간 길이를 임의로 환산하거나 단위를 변환하지 않는다.
- 비교 결과는 모델이 생성하지 않는다. 저장된 계획을 읽을 때도 입력 계약에서 다시 계산한다. 등록하지 않은 비교 주장을 자동으로 찾아내거나 사실 검증이 완료됐다고 표시하지 않는다.
- 새 계획은 q2b-v1이며 Deck schema_version 1을 유지한다. 기존 q2a-v1 계획의 fingerprint 입력을 그대로 보존하여 새 기본 필드 때문에 유효한 옛 계획이 만료되지 않게 한다.
- 계획 생성, 승인/저장/재읽기, 장 생성/축약 문맥과 화면까지 연결한다. 불가/불충분인 비교는 직접적인 우열, 증감이나 차트의 근거로 사용하지 말고 한계와 확인 사항을 남기도록 생성 지침에 전달한다. 생성된 문장이 이를 준수하는지 독립 검수하는 것은 후속 범위다.

## 구현 전 반증 검토

- null 두 개를 같다고 처리하면 미확인이 통과한다. 빠진 조건은 개별 사유로 반환한다.
- 서로 다른 기간을 무조건 실패시키면 정상적인 추이 비교를 막는다. 비교축을 명시하고 기간 비교는 완결된 같은 달력 단위와 집계 방식, 비중첩을 검사한다. 부분 기간/기타 기간은 보류한다.
- 원/천원, 등록자/응답자, 매출/순매출을 이름이 비슷하다는 이유로 통합하지 않는다. 정확한 계약 일치만 확인하며 의미상 동의어 판정과 단위 변환은 수행하지 않는다.
- 모델/저장 파일의 성공 상태를 신뢰하지 않는다. 결과를 코드가 재계산하고 fingerprint에 결합한다.
- 신규 필드를 추가하면 옛 fingerprint가 달라질 수 있다. 변경 전 q2a 계약을 독립적으로 재구성한 회귀 사례로 확인한다.
- 테스트는 형식/판정/왕복 범위만 입증한다. 실제 제공자, 의미 검수, 사람 품질 평가는 미수행으로 남긴다.

## 완료 조건

조건 일치/불일치/누락, 비교축, 기간 경계, 잘못된 참조와 재시도 상한, 결과 재계산, q2a 호환, 저장/프롬프트/화면 왕복을 검증한다. OpenAPI/TypeScript를 갱신하고 전체 테스트와 빌드를 수행한다. 로드맵과 아키텍처에 실제 계약과 미완료를 반영하고 다음 인계 지점에서 멈춘다. 계산기, 의미 검수, 부분 재계획, 실제 AI 호출과 커밋/푸시는 이번 범위에 포함하지 않는다.

## 실행 결과

위 범위를 구현하고 백엔드 1,033개 중 실패 0개, 프런트 265개 중 실패 0개(25개 파일), tsc/Vite 빌드, OpenAPI/생성 타입 일치를 확인했다. 새 회귀 사례는 백엔드 46개와 프런트 8개다. 신규 입력과 화면 영역이 없는 상태에서 테스트 실패를 먼저 확인했으며, 프런트 타입 검사에서 누락된 모의 데이터 필드도 수정했다.

실제 변경 전 q2a 저장본으로 fingerprint 호환을 확인했다. 조건 일치/불가/정보 부족의 HTTP 응답과 빌드 파일 제공은 별도 임시 서버에서 확인했다(4건 중 문제 0건). 외부 AI 프로바이더를 연결하지 않았고 임시 서버는 검사 후 종료했다. 실제 브라우저 표시는 브라우저 연결과 네이티브 앱 창 접근 오류로 확인하지 못했다.

`engineering:code-review`의 정확성/보존/경계 조건 기준으로 자체 검토했다. 독립 에이전트 리뷰는 수행하지 않았다. 실제 AI 스키마 수용성, 의미 검수, PowerPoint와 독자 품질 평가는 남아 있다. 해당 한계를 상위 로드맵에 반영했으며 [Q2b 인계](../handoffs/2026-09-12-q2b-metric-comparison-handoff.md)를 다음 작업의 기준으로 삼는다.
